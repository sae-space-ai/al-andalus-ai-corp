# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto sigue [Semantic Versioning](https://semver.org/lang/es/).

## [Unreleased]

### Added
- Integración con APIs reales (OpenAI, Claude)
- Sistema de autenticación completo
- Backend con Supabase
- Testing E2E con Playwright

## [2.0.0] - 2026-01-15

### Added - Fase 7: Revisión Completa
- Optimización completa del código
- Eliminación de variables globales
- Mejora de accesibilidad (aria-labels)
- Limpieza de imports no utilizados
- TypeScript estricto en todo el proyecto

### Fixed
- Problemas de sincronización con el idioma
- Errores de TypeScript en producción
- Performance en re-renders innecesarios
